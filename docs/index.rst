scanpath_nlp_metrics
===================

A Python library for comparing scanpaths using VLM-generated descriptions and spatial metrics.

Features
--------

- **NLP Metrics**: ROUGE, BLEU, BERTScore, BM25
- **Spatial Metrics**: ScanMatch, DTW, Hausdorff, Levenshtein, TDE
- **MultiMatch**: Vector, Direction, Length, Position, Duration similarity
- **VLM Integration**: Support for patch-based and marker-based gaze description
